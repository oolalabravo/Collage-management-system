
**Description:**
Revolutionize attendance with **QR codes, automation, and real-time analytics**! This Flask & MySQL-powered system lets schools and colleges **track attendance securely, send instant alerts, and generate reports with a click**. Perfect for hackathons and modern classrooms.

**Highlights:**

* 📱 QR code-based attendance scanning
* 🔒 Secure login & encrypted data with bcrypt
* 📧 Automated low-attendance email alerts
* 📊 Analytics dashboard & downloadable reports
* ⚡ Fast, scalable, and hackathon-ready

**Tech Stack:** Python | Flask | MySQL | Pandas | qrcode | Gmail API
